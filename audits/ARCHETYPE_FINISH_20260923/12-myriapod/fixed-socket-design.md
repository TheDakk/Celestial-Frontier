# Compact myriapod fixed-socket infrastructure

Implementation scope: a source-owned socket is fixed rest geometry, with no animation channel or additional joint. The explicit `myriapod-rigid-trunk-v1` graph retains two real walking-leg bones. Fourteen walking pairs contribute56 joints, head/root/mandible/two antennae contribute5, and two ultimate-leg controllers yield63 total. The64-joint and32-part caps, bone/angle limits, 8percent compression cap, endpoint tolerance and painted-point tolerance remain unchanged. Ultimate legs have explicit nonwalking roles; no painted leg is removed.

`resolveFixedAttachments(template,record,alpha?)` validates `record.geometry.fixedAttachments` and returns copied/frozen `fixedPivots` on the definition. Required keys are exactly `head`, every walking leg's `Knee`, and `ultimateFar`/`ultimateNear`. All sockets are finite normalized source points attached to the declared root parent. Missing, extra, malformed, foreign-family or mismatched previously resolved pivots refuse. When source alpha is available, each socket must lie on a positive-alpha source pixel; the closed normalized edge maps to the last pixel. No search, clamp, inferred anatomy or mutation is performed.

The old definition object is returned unchanged when neither compact-model nor socket declaration is present. `validateFixedPivots` protects standalone skeleton/measurement consumers from using an unbound compact definition. Legacy quadruped admission shortcuts explicitly reject attempted socket declarations.

The skeleton's `pivot()` and pose matrices, family admission bone lengths, body-card part pivots/bone lengths/leg slack and contact chain hip construction consume the same socket coordinates. Knee rotates about its fixed socket; Foot rotates about the actual knee. Contact transforms the socket through the root/hip matrix and uses the existing two-bone solve. Head uses its explicit neck/front socket because the model's root/body-axis point sits at the posterior trunk. Mandible and antennae retain their head parent pivot.

The root-owned contract resolver must apply `resolveFixedAttachments` after compact anatomy expansion. Body-card compilation applies the same resolver after motion anatomy expansion. Parent-owned count-aware actions must omit nonexistent trunk segment-wave channels and define the rigid trunk approximation explicitly. Parent-owned regional painter weights must still represent both real leg rotations and head/mouth/antenna articulation within32 paint parts; these are not implemented by socket geometry.

Final static, native CPU and S2 qualification remain parent-owned.
