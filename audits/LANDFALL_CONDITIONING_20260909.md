# Canonical species conditioning compiler — 2026-09-09

This bounded source batch adds a pure compiler for the existing exact Earth epoch-0 appearance snapshot. It does not implement a universal anatomy classifier, enlarge the admitted world/biome scope, or accept generated art. The parent integration batch owns game/proof wiring, reference preparation, source review, runtime validation and handoff.

## Owned files and API

- `port/v2/apps/game/src/landfall-conditioning.ts`
- `port/v2/tests/landfall-conditioning.test.ts`
- This independent scope/evidence note.

`buildCanonicalLandfallConditioningV1(request, liveRoster)` first uses the established live-roster snapshot owner. `buildLandfallConditioningV1(snapshot)` supports the same detached JSON snapshot as conditioning data, reusing the existing full-request/all-19-roster Earth gate and exact six-resident plan. Parsed data never gains the private live-roster brand.

Success returns `recipe`, `snapshotKey`, `recipeKey` and `canonicalJson`; refusal is explicit. The recipe preserves the complete snapshot, all 19 genomes, all six displayed full-genome `speciesVisualKey` identities, accepted normalized placements, named diagnostic records and provenance, shared style version, prompt and exclusions. Keys contain the complete versioned canonical JSON bytes; an outer storage/transport owner may hash those bytes. They are not new random seeds or promises of regenerated pixel identity.

The single required reference slot is Image 1: the exact canonical Platypus identity and full genome, with defining features and review-required status. The compiler neither locates nor approves an image. `referenceStatus` remains `unresolved`, `qualityAccepted` remains false, and `fidelityGuarantee` explicitly requires outcome review. The model adapter must bind the reviewed reference, apply its pinned tokenizer/chat template, refuse overflow rather than truncate, and determine which exclusion mechanisms it actually supports. A `negativePrompt` string alone does not imply that the current sampler consumes it.
