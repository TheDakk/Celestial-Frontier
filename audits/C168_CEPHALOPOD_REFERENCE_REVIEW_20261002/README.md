# C168 cephalopod reference source review

The two inspected C163 originals are retained unchanged. Giant Octopus has eight distinct visible arm tips, but only one confidently visible eye. Cuttlefish has two clear feeding tentacles; the short arms overlap and the far eye cannot be confidently placed. `observations.json` records exact source hashes and approximate visual coordinates, without substituting requested counts for observed anatomy.

The current cephalopod graph needs both eye joints. Its optional `eyes` declaration removes both eyes, and the hidden-anatomy owner supports only specified crab leg chains. Calling these animals eyeless, assigning an invented far-eye point, or copying donor coordinates would make a false reference. No such packet was made and no runtime contract was weakened.

The source-side next step is a new painting with a three-quarter view exposing both eyes, separate arm silhouettes and the actual siphon; the cuttlefish must retain eight arms plus its two feeding tentacles and lateral fins. A one-eye rendering needs explicit future template support, which cannot silently enter the already certified product. This review is not a reference admission, a new painting, or a native result.
