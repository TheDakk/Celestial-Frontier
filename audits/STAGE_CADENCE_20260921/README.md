# Body-length cadence run

Whole cycles preserve the composed run-up distance; each cycle advances at most0.2 body lengths (each half-cycle stance at most0.1, inside Nick’s0.2 maximum). Time is N times the unmodified gait duration. The shared helper emits signed stance-local body lengths and world pixels separately. No solver/skin/limits/clip changes.

Battle2 is absent from this checkout and the sibling is read-only. This producer exposes the shared cadence; the native harness consumes it. Claude’s integration must feed worldDisplacementPx to the holder and stageDisplacement unchanged into ContactPhase, removing its old division by card.scaleLength. Full battle choreography integration is not claimed here.
