# D40 source-specific donor exclusion — review proposal only

`proposal.json` defines one optional source-recipe exclusion list. It never adds a donor or changes source support, classifier, thresholds, seals or rulers. The unchanged donor map/default result remains authoritative. A second map omits only exact reviewed seed indices and is consumed only by explicit existing `despillPixels` targets. All channels outside those targets stay default-byte-identical. Missing/empty exclusions retain historical RGBA and algorithm-receipt bytes; truthful wrapper implementation fingerprints will change if code is later changed, and old receipts stay immutable.

Alternate RGB must come from an actual eligible source pixel reachable through the same original supported component. No neutral-white heuristic, palette replacement or fabricated reverse paint is proposed. Changed alpha cannot exceed default D40 alpha, so no new positive pixel, opacity growth or bridge is allowed. No reachable donor preserves baseline RGBA and records an explicit unresolved target/HOLD; it cannot fall back to raw full alpha or a donor across a source gap.

There is no production job.
