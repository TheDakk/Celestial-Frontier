# Use this package

1. Extract this folder into the Celestial Frontier repository (or attach its files to the coding agent working on that repository).
2. Paste the contents of PASTE-INTO-CODING-AGENT.txt into that agent.
3. The agent should read CELESTIAL-FRONTIER-AUDIO-HANDOFF.md and audio-sources.json, then implement the downloads, production workflow, integration and checks.

This is an instruction package, not an installer or a collection of recordings. It does not contain executable automation, REAPER projects, Surge patches, or completed sound assets. The coding agent is instructed to create and test those in the actual project. Media downloads and local DAW operation must happen in an authorized, network-enabled environment with access to your installed applications.

The source manifest contains 15 official source pages: 11 sound/jingle packs, two music tracks and two NPS collections. Source-page checks do not establish complete species coverage, production readiness, or the quality of individual recordings.

New asset/software purchase budget: $0. Existing REAPER licensing is not changed by this package. REAPER is the user's already installed tool, not being represented as open-source software.
