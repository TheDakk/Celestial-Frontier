CELESTIAL FRONTIER V2
Pixel-art expansion references

These ten generated concept boards extend the earlier reference pack. All are flat visual references. The style prompts describe visual density. For game assets, author native-grid sprites and separate environment layers.

The sheets illustrate forms and variations, without implying that the current game generates these particular plants.

EXTENDING THE FLORA SET
For an Earth species, start from its botanical reference and preserve its whole shape and identifying organs. For a procedural species, start with a resolved form and use versioned style rules to vary height, branch spread, leaf shape, seed or fruit placement, and palette within a compatible family. Build visibly attached organs. Draw a small inventory or Compendium icon from the same plant identity, and keep any light confined to the tissue that emits it. Use the existing genome and resolved form as the authority for in-game variants.
