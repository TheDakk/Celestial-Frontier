# Controlled creature painting tools

Matches code as of 2026-10-02.

`compile-library-master.mjs` compiles a canonical Earth fauna name, genomic identity, ART_KIT prompt and locked style reference into a new immutable request packet. It supplies painting vocabulary for quadruped, bird, serpent, fish, insect, primate, myriapod, cephalopod and membrane-wing flyer families. The four extended routes require an explicitly supported named species; mixed or unknown family routing refuses. Existing five-family layouts are unchanged. Primates preserve real arms/hands and species tails; myriapods preserve their own leg-pair pattern rather than a rig joint count; cephalopods distinguish eight arms, feeding tentacles, sensory filaments, fins and the Nautilus shell; bat wings are forelimbs. This is prompt support, never rig, motion, attack or gallery admission.

`reviewed-presence.mjs` accepts two separate explicit review schemas. `cf.reviewed-optional-absence/v1` retains the existing canonical tailless-quadruped tail policy. `cf.reviewed-external-ear-absence/v1` admits external-pinna absence only for a hash-bound adult sprawler painting whose independent pinned Earth profile is lizard, special-lizard, marine-iguana, crocodilian or salamander. Both routes bind exact master, canonical subject and prompt bytes and require full-original review. The ear route also binds the complete current Earth profile and accepts only `external-pinnae-only`, one absence decision and `exact-master-only-no-visual-admission` scope. Ear openings, tympana, protective flaps, horns, casques, frills and gills remain natural head/neck paint. Mammals and changed/rebound canonical or profile assertions refuse. Failed paint ownership never implies absence.

The independent profile registry is bundled once at tool import using the locked Rolldown dependency, retaining supported Node 20+ operation without native TypeScript imports. The returned presence declaration feeds a new author/intake; it never patches sealed output. Removing the four optional ear joints preserves mandatory body geometry, all four legs and the full tail. References still require intake/static/native checks, full-size review and leave-one-species-out controls before pool addition.

The C136 reference and exact-review candidates are in `audits/C136_SPRAWLER_REFERENCES_20261002`. The compiler/adapter integration evidence is in `audits/C136_COMPILER_PRESENCE_20261002`. Focused Node tests cover the existing tail route, exact ear reviews and negative controls, all 32 extended canonical names, unchanged existing layouts, species-dependent anatomy requests and full canonical prompt compilation. No certificate, gallery or runtime-topology admission follows from these tests.
