the audit that was hunting for vacuous gates** (defect class 4 of its own brief).

shape and joined on `species`** — a stable key — and **all 473 of its FAIL rows carry a real
verifier trace**, with 31% of stated causes corrected on re-check. Same harness, one keyed on
an identifier and one on prose. **Join on an identifier, never on model-authored text.**

## 2. HIGH findings (ordered by blast radius)

### H1 — `skin.ts:595` · false-comment (live render implication) · **~105 birds (whole catalogue)**
**Claim.** The feather branch's comment says rows are "drawn ventral → dorsal so each row
overlaps the one beneath it" and warns that reversing this makes the bird look "assembled
backwards" — but the loop draws dorsal FIRST and ventral LAST: the exact reversal.
**Trace.** `torso.ts:35` fixes the convention (phi −π/2 ventral, +π/2 dorsal). `skin.ts:595`
`for (let ri = rows; ri >= 0; ri--)` with `:596 phi = -1.40 + (ri/rows)*2.85` gives
phi=+1.45 (dorsal) on the first iteration, phi=−1.40 (ventral) on the last — ventral rows
paint on top. The scale branch (`:761`, ascending loop with the inverted phi formula)
produces the identical dorsal-first order: the loop reversal and formula inversion cancel,
so the intended order flip is a no-op. Either the shipped overlap is backwards (per the
comment's own warning) or the comment lies — the contradiction holds either way.
**Species.** Every 'feather'-material species: bird body painter (`faunaoverrides.ts:710`)
and wing coverts (`faunaoverrides.ts:830`); ~105 birds per `skin.ts:617-618`.
**Fix (exact shape).** Flip the loop to ascending — `for (let ri = 0; ri <= rows; ri++)` —
and keep the phi formula at :596 unchanged, so ri=0 paints ventral first and dorsal rows
land on top, matching the comment's stated intent. Do not patch the comment first: it
states the intent; the loop is the suspect. Proof-sheet a spread of birds before/after;
only if the current ventral-on-top look is judged correct on the sheet does the fix become
"rewrite :592-594 to say dorsal → ventral and delete the warning." One of the two edits
must land — the assert/refute pair cannot stand.

### H2 — `port/v2/packages/art/src/faunaoverrides3.ts:195` · inert-option · **Tripod Fish + an unbounded procedural class**
**Claim.** `tail:'point'` paints a zero-area path (no tail at all) whenever the profile is
'fusiform', 'deep', or 'globe', because every anchor of the point-tail shape is scaled by
`pedH = heightAt(profile, 0, depth)`, which is exactly 0 for those profiles. The fin rays
(:201-205) still draw, so the fish shows seven orphan ray strokes with no membrane.
**Trace.** `heightAt:100` `bell = sin(PI * 0**0.85) = 0` at t=0; `:102/:103/:107` return
`depth*f(bell) = 0` for deep/globe/fusiform (only box/eel/ribbon have a nonzero floor).
`:164` `pedH = heightAt(spec.profile, 0, depth)`. `:195-199` moveTo/quadraticCurveTo all
scaled by pedH → start and end collapse to (ped, cy): a degenerate line, fill paints nothing.
**Species.** Tripod Fish (`:845`, the only static row pairing 'point' with a zero-peduncle
profile); every procedural swimmer (loco 4/13) rolling tail%5===3 with body not 4/12
(`proceduraloverrides.ts:100-103`) — an ongoing class, not a fixed roster.
**Fix (exact shape).** In the point-tail branch, floor the scale with the already-computed
tRef: `const ph = Math.max(pedH, tRef * 0.6);` and replace the pedH reads in :195-199 with
`ph` (tRef = heightAt(profile, 0.14, depth), line 165 — nonzero for all profiles). Do NOT
change heightAt itself: the 0-at-peduncle contract is load-bearing for the body silhouette.

### H3 — `floraoverrides2.ts:523` · inert-option · **12 plant species**
**Claim.** `thorns` is read only inside the succulent habit's non-pad sub-branch, but 12 of
its 13 setters are trees, shrubs, vines, rosettes, or the pad succulent — their thorns
never draw. Even Prickly Pear (the cactus) misses: `leaf:'pad'` routes it into the pad

AND the else of `leaf==='pad'` (:503). Writers in florarost.ts: Durian:36, Mesquite:45,
Sea Buckthorn:49, Acacia:88, Rattan:104, Blackberry:118, Raspberry:119, Gooseberry:135,
Rose Hip:139, Castor Bean:215, Agave:291, Prickly Pear:293 — all miss. Only Barrel Cactus
Fruit:294 (succulent, leaf:'scale') reaches it.
**Species.** Durian, Mesquite, Sea Buckthorn, Acacia, Rattan, Blackberry, Raspberry,
Gooseberry, Rose Hip, Castor Bean, Agave, Prickly Pear render thornless.
**Fix (exact shape).** Hoist the thorn body out of the succulent nest into a
habit-independent post-pass gated only on `spec.thorns`, run after each habit's stems/trunk
are stroked: keep the existing rib-spine code for succulent columns; add paired spurs along
the shrub/vine stem beziers (~every 0.12H) and along the tree trunk stroke (:315); add a
pad-branch block (rim dot clusters) for Prickly Pear. Proof-sheet all 13 setters.
